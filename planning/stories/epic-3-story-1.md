# Epic 3 — Story 1: Serve the static same-origin explorer shell and assets

**Status:** Done

## User Story Goal

As a developer, I want a lightweight explorer page and same-origin assets so that I can open the API catalog without installing a third-party UI.

## Prerequisites

Epic 2 Story 3 — Activate the explorer with production fail-closed behavior

## Injected Technical Context

Create `src/api_explorer/assets.lua` and complete asset routes in `src/api_explorer/explorer.lua`; add the module to rockspec. Assets are `M.html`, `M.css`, `M.js` as Lua `[==[ ... ]==]` strings, under 50 KiB total. HTML is semantic and static, contains only `<script src="/__guaraci/explorer/app.js"></script>`, no inline script, inline event handlers, external origin, CDN, framework, `eval`, or `new Function`.

Responses are HTML `text/html; charset=utf-8`, JS `application/javascript; charset=utf-8`, CSS `text/css; charset=utf-8`. HTML emits `Set-Cookie: guaraci_csrf_token=<64 hex chars>; Path=/; SameSite=Lax`, generated by `guaraci_random.hex(16)` and intentionally not HttpOnly so JS can double-submit it. Dynamic catalog data is never interpolated into HTML.

Applicable PRD text (verbatim): “A página deve carregar somente assets same-origin”; “A UI deve listar todas as operações agrupadas ou filtráveis por método HTTP e caminho”; “Cada operação deve renderizar parâmetros de caminho como campos obrigatórios”; “Ao servir a página do explorer, o servidor deve disponibilizar o cookie `guaraci_csrf_token` com valor aleatório seguro, `Path=/` e `SameSite=Lax`.” NFR01/NFR02/NFR03/NFR06 also apply.

- `#assets.html + #assets.css + #assets.js < 50*1024`; no URL references an external origin.
- Explorer HTML response sets a 64-hex-character token with `Path=/; SameSite=Lax`.
- A malicious operation/field name is rendered using `textContent`/`createElement` semantics, not HTML concatenation.
